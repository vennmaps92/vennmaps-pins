# VennMaps Rock Layers + Face-off carousels
- **Alan approved the CO mockups (Nov 8)** and asked for all 48 states, auto-posted, starting that week. Built in a cloud session (no PC access), so slides use a stand-in serif (Latin Modern) instead of Bodoni; the map images are crops of each state's carousel slide 3 (`c/<ST>_ig_3_full.jpg`).
- **Rock Layers** (48 posts): cover (stylised drill core + state geology map, "Dig down through N years") → one slide per layer, youngest → oldest (4–6 layers: name, age, hook, what it was, red bonus fact, pins on the state map "Where to see it") → the state's Etsy slide (holiday version Nov 20 – Dec 10; non-shop states get their "Want it on your wall?" slide). 6–8 slides. Core colours = muted period colours + lithology patterns.
- **Face-off** (24 neighbour pairs: CO-UT, WA-OR, ID-MT, CA-NV, AZ-NM, WY-SD, ND-MN, WI-MI, NE-IA, KS-MO, OK-TX, IL-IN, KY-TN, AR-LA, MS-AL, GA-FL, NC-SC, VA-WV, MD-DE, PA-OH, NY-NJ, CT-RI, MA-VT, ME-NH): cover → 5 scored rounds (winner gets POINT, running score) → bonus vote ("Comment X or Y") → final score + Etsy (both shop: "Can't pick? Hang both"; one non-shop: "{shop} is on Etsy · Want {other}? Comment"). 8 slides.
- **Schedule:** Rock Layers **Tue + Thu 9:00 AM Denver**, Nov 10 2026 → Apr 22 2027 (same state order as the Mon/Wed/Fri carousels); Face-off **Saturdays 9:00 AM**, Nov 14 2026 → Apr 24 2027 (CO-UT first, then two-shop pairs). In `igc/schedule.json` (keys `<date>_0900_<ST>_layers` / `<date>_0900_<A>-<B>_faceoff`, `series` "Rock Layers" / "Face-off", state "CO-UT" for pairs) — same igc poster, no code change. igc now 120 posts.
- **Files:** slides on reels branch `c/<ST>_rl_<n>.jpg`, `c/<A>-<B>_fo_<n>.jpg` (+ `_holiday` last slide), 596 JPGs ~121 MB. Source data + generator on main in `igc/series/` (`data/layers/*.json`, `data/faceoff/*.json`, `gen.py`, `detect.py` map-box finder with manual fixes for MA/IN/RI/KY, `sched.py`).
- **Master calendar:** rows not yet added from the cloud. `igc/add_calendar_rows.py` (in the repo) adds the 72 green "Instagram carousel" rows to the Calendar tab, copying the style of an existing carousel row, sorted by date; skips rows already there; backs up first. Run on the PC with Excel closed.
- **Facts caveat:** layer/face-off facts were drafted by research subagents whose web search returned no page text, so most are from model knowledge with spot fixes (PA Lake Erie shore → ~63 mi; layer order sorted by age; IL/RI/VT reordered). Flagged as least certain: ages of several granites (Concord, Barre, Stony Creek, Quincy, Winnsboro, Mount Airy), NV Comstock/Lahontan ages, AL Bangor/Cathedral Caverns link, NC-SC lake round (Lake Marion is man-made), MD-DE is a 5–0 sweep, MS-AL 1–4, OK-TX 1–4, NY-NJ 4–1, rain-based rounds in NE-IA/KS-MO/OK-TX.
